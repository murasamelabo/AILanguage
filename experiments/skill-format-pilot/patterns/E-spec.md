L0 reading rules
One rule per line. No articles, no inflection, no plural. Fixed order: MODAL topic = body.
Modal: MUST, NEVER. A line with no modal is a definition.
Compound words are head-final; the last part gives the type:
-line one output line, -list ordered lines, -text free text, -val literal value, -n number, -path file path.
Symbols: = is; -> becomes; | or; & and; / else; @ located in; <= at most; > then by;
; separates clauses; `x` exact output text; {x} placeholder; if C: applies only when C holds.
